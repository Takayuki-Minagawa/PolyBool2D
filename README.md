# PolyBool2D

PolyBool2D is a browser-only 2D CAD application for drawing polygonal regions,
editing their geometry, running boolean and offset operations, and exchanging
drawings through JSON, SVG, PNG, DXF, GeoJSON, CSV, or a share URL.

PolyBool2D は、建築・構造・設計検討などで扱う平面領域を作図・編集し、
面積確認やブーリアン演算、簡易な CAD データ交換を行うための 2D Web アプリです。
バックエンドを必要とせず、静的サイトとしてブラウザ内で動作します。

> PolyBool2D は設計検討を補助するツールです。法規、構造安全性、契約、施工などの
> 重要な判断では、責任者による確認と、信頼できる CAD・構造計算・設計支援ツールでの
> 再検証を行ってください。

## 特徴

- 外周と複数の穴を持つポリゴンを基本モデルとする SVG ベースの 2D CAD ビューポート。
- ポリゴン、矩形、円、楕円、穴、円弧、ポリライン、補助線の作図。
- 距離・累積長・角度を確認する測定ツールと、保存・再編集・書き出し可能な
  線形寸法、角度寸法、テキスト注記。
- グリッド、頂点、辺、中点、補助線へのスナップと、任意で有効化できる 15° の角度スナップ。
- `Shift` による水平・垂直拘束と、作図方向に対する正確な長さ入力。
- 作図中の辺長、半径、W×H、累積長、角度を表示する寸法 HUD。
- Clipper2 を既定エンジンにしたブーリアン演算とネイティブオフセット、拡張ナイフ分割、
  自己交差修復、面取り、フィレット、
  凸包、単純化、最小外接矩形、整列・分布。
- 断面二次モーメント、断面係数、回転半径の表示と印刷用断面性能レポート。
- 辺長・水平・垂直・角度・平行・直交のパラメトリック拘束。
- レイヤー、エンティティアウトライナー、表示・ロック、コピー・カット・ペースト、
  グループ、部品テンプレート、右クリックメニュー、Undo / Redo。
- IndexedDB に保存する下絵画像、両軸ルーラーからの補助線作成。
- 複数ローカルプロジェクト、自動保存、プロジェクトごとの最大 10 世代バックアップ。
- JSON / SVG / DXF / GeoJSON インポート、JSON / SVG / PNG / DXF / GeoJSON / CSV
  エクスポート、共有 URL。
- manifest と Service Worker によるインストール可能なオフライン対応 PWA。
- 日本語 / English、ライト / ダークテーマ、アプリ内マニュアルとショートカット一覧。

## 画面構成

- **ヘッダー**: 新規作成、ローカルプロジェクト管理、JSON / SVG / DXF / GeoJSON /
  下絵読込、各形式への出力、断面レポート、
  共有 URL、Undo / Redo、言語・テーマ、ショートカット一覧、マニュアル。
- **ツールバー**: 作図・選択ツール、ブーリアン演算、グリッド・スナップ、
  コピー / カット / ペースト、複製、削除。
- **キャンバス**: 図形・寸法・注記の作図、下絵、ルーラー、選択・移動・頂点編集。
  右下にズームと全体表示を配置。
- **プロパティパネル**: 面積・周長・外接寸法・重心・断面性能、変形、頂点と穴、
  レイヤー、アウトライナー、グループ・部品・拘束、下絵、ジオメトリ操作、設定。
- **ステータスバー**: 現在のツール、スナップ / グリッド状態、選択面積、操作ガイド、エラー。

## ツール

| キー | ツール | 操作 |
| --- | --- | --- |
| `V` | 選択 | クリックで選択、`Shift` + クリックで追加・解除。ポリゴン本体をドラッグして移動 |
| `H` | パン | ドラッグで表示範囲を移動 |
| `P` | ポリゴン | クリックで頂点追加。`Enter` または始点付近のクリックで確定 |
| `R` | 矩形 | 対角線をドラッグ。`Shift` で正方形 |
| `C` | 円 | 中心から半径をドラッグ |
| `O` | 楕円 | 中心から X / Y 半径をドラッグ |
| `A` | 円弧 | 中心、始点、終点の順に 3 点をクリック |
| `L` | ポリライン | クリックで点を追加し、`Enter` で確定 |
| `U` | 穴 | ポリゴンを 1 つ選択してから穴リングを作図 |
| `D` | 補助線 | 2 点をドラッグして無限補助線を配置 |
| `M` | 測定 | 点を順にクリックして距離・累積長・角度を一時表示。`Enter` で終了 |
| `N` | 線形寸法 | 計測始点、終点、寸法線位置の順にクリック |
| `J` | 角度寸法 | 中心、第 1 方向、第 2 方向の順にクリック |
| `T` | 注記 | 配置位置をクリックしてテキストを入力 |
| `E` | 頂点編集 | 頂点をドラッグ。`Alt` + 頂点クリックで削除 |
| `K` | ナイフ | 対象ポリゴンを選択し、境界を横切る直線をドラッグ |

円と楕円はポリゴン、円弧は折れ線へ近似して保存します。近似分割数はプロジェクト設定の
「円分割数」を使用します。

## 精密作図

### スナップと直交拘束

スナップを有効にすると、表示中のポリゴンと線要素を空間インデックスで検索し、
グリッド、頂点、辺、中点、補助線へ吸着します。点列作図では直前点を基準に方向を
角度スナップを有効にすると既定 15° 刻みへ量子化します（初期状態は無効）。有効 / 無効と刻み角はプロジェクト設定で
変更できます。作図中に `Shift` を押すと 90° の水平・垂直拘束が優先されます。
矩形では `Shift` が正方形拘束も兼ねます。

### 長さの数値入力

ポリゴン、穴、ポリライン、測定などの作図中にカーソルで方向を示し、正の数値を入力して
`Enter` を押すと、直前点からその距離に次点を配置します。小数点には `.` または `,` を
使えます。円、補助線、ナイフも対応するプレビュー中に長さを適用できます。
入力値はキャンバス上の数値 HUD に表示されます。

### 寸法 HUD と測定

作図プレビューは、ポリゴン・穴・ポリラインの各辺長、矩形の W×H、円・円弧の半径、
楕円の X / Y 半径、補助線・ナイフの長さを現在の座標単位で表示します。測定ツールは
各区間長、累積長、直近 3 点の角度を一時表示します。線形寸法・角度寸法ツールは
結果をプロジェクトへ保存し、JSON / SVG / PNG / DXF 出力にも含めます。

## 編集と管理

### 頂点と穴

- 選択ポリゴンの外周・穴の頂点ハンドルをドラッグできます。
- プロパティパネルでは外周と各穴の X / Y 座標を編集し、辺の中点へ頂点を挿入、
  頂点または穴全体を削除できます。
- 穴ツールは、選択した 1 ポリゴンの内側へ 3 点以上の閉リングを追加します。
- 自己交差、外周との交差、外側の穴、穴同士の重なりは拒否されます。
- 頂点編集後に不正となったポリゴンは赤い輪郭で表示され、ステータスバーに理由を表示します。

### レイヤーとアウトライナー

- レイヤーの追加、作図先の指定、名前・色の変更、表示、ロック、削除ができます。
- レイヤー削除時、そのレイヤーのエンティティは残っている別レイヤーへ移されます。
- 非表示またはロック中のエンティティはキャンバスから選択・編集できません。
- アウトライナーでは全エンティティを一覧し、名前、表示、ロック、所属レイヤーを編集できます。
- 選択をパネルまたは右クリックメニューから別レイヤーへ移動できます。

### クリップボードとコンテキストメニュー

`Ctrl/⌘ + C/X/V` はポリゴンと線要素に対応します。貼り付けるたびに新しい ID を割り当て、
グリッド間隔に応じて段階的にずらします。ロック中のエンティティはコピー・カット対象外です。
右クリックメニューからもコピー、カット、貼付、複製、Union、Difference、削除、
レイヤー移動を実行できます。

## ジオメトリ操作

- **Union**: 選択ポリゴンを結合。
- **Difference**: 最初の選択を対象、残りをカッターとして差し引き。
- **Intersection / XOR**: 共通部分 / 排他的領域を生成。
- **Knife**: 直線の両側とのクリッピングで分割。穴付きポリゴンと複数交点に対応し、
  分割前後の面積を検証します。ストロークは境界と 2 点以上で交差する必要があります。
- **Offset**: 正の距離で外側、負の距離で内側へ丸め結合のバッファを新規作成。
  結果は複数ポリゴンへ分かれたり、内側オフセットで消失したりする場合があります。
- **Repair**: 自己交差・自己接触を非ゼロフィル規則で正規化し、選択を修復結果で置換。
- **Chamfer / Fillet**: 選択ポリゴンの全頂点を指定寸法で面取り / 円弧近似。
- **Minimum bounds**: 選択頂点群を囲む最小面積の回転矩形を新規作成。
- **Convex hull / Simplify**: 選択頂点の凸包作成 / Douglas-Peucker による頂点削減。
- **Transform**: 90° 回転、任意角度回転、左右・上下反転、固定または X / Y 任意倍率の拡縮。
- **Align / Distribute**: 2 図形以上の端・中心揃え、3 図形以上の等間隔分布。

各変更操作は Undo / Redo の対象です。ブーリアン、変形、高度なジオメトリ操作は
ポリゴンを対象とします。

## プロジェクト、保存、共有

### ローカルプロジェクト

現在のプロジェクトは変更後約 400 ms でブラウザの `localStorage` へ自動保存されます。
ヘッダーの **プロジェクト** から、保存済みプロジェクトを開く、名前変更、複製、削除できます。
旧単一キー `pb2d.project` のデータは初回に複数プロジェクト形式へ移行されます。

保存内容が変わるたび、直前の正常な保存値をプロジェクトごとに最大 10 世代保持します。
プロジェクト一覧の **バックアップ** から日時とエンティティ数を確認し、任意世代を復元できます。
これは同一ブラウザ内の簡易世代管理であり、端末故障、ブラウザデータ消去、ストレージ容量超過に
備える外部バックアップではありません。重要な作業は JSON にも書き出してください。

### 入出力

| 形式 | 読込 | 書出 | 内容 |
| --- | :---: | :---: | --- |
| Project JSON | ✓ | ✓ | レイヤー、設定、ポリゴン、線要素を含む完全なプロジェクト |
| SVG | ✓ | ✓ | 対応図形をポリゴン化。書出は表示中の図形・線・寸法・注記 |
| PNG | — | ✓ | SVG 書出結果を透明背景のラスター画像へ変換。長辺は最大 4096 px |
| DXF | ✓ | ✓ | `LWPOLYLINE` / `POLYLINE` / `LINE` / `ARC` / `CIRCLE` を読込。寸法は線と `TEXT` に分解して出力 |
| GeoJSON | ✓ | ✓ | `Polygon` / `MultiPolygon` と穴を双方向変換 |
| Area CSV | — | ✓ | ポリゴンの面積・周長と、ポリライン・円弧の長さ（面積欄は空） |
| Vertex CSV | — | ✓ | 外周・穴・ポリライン・円弧の全頂点座標 |

SVG の直線パスは `M/L/H/V/Z` の絶対・相対コマンドに対応します。曲線パスはブラウザが
`getPointAtLength` を提供する場合にサンプリングします。SVG の見た目や全要素を完全再現する
インポーターではありません。

### 共有 URL

**共有 URL** はプロジェクト JSON を gzip（利用可能なブラウザ）と base64url で URL ハッシュへ
埋め込み、クリップボードへコピーします。受信側で URL を開くと、ローカルの作業より共有データを
優先して読み込みます。ハッシュが 8,000 文字を超えるプロジェクトは共有 URL を作成できません。
URL を知る人はデータを復元できるため、機密図面の取り扱いに注意してください。

## データモデル

共有ジオメトリ型は `src/geometry/types.ts` にあります。

```ts
type Point = { x: number; y: number };
type Ring = Point[];

type PolygonGeometry = {
  outer: Ring;
  holes: Ring[];
};

type MultiPolygonGeometry = PolygonGeometry[];
```

リングは始点を末尾へ重複させない open ring として保存します。正規化時に座標を小数 9 桁へ
丸め、隣接重複点を除去し、外周を反時計回り、穴を時計回りへ揃えます。面積計算には
ローカル原点と補償和を使った Shoelace formula を使用します。

プロジェクト JSON のルート型は `src/app/projectTypes.ts`、検証は
`src/persistence/projectCodec.ts` にあります。主な項目は次のとおりです。

- `id`, `name`, `version`, `unit`, `createdAt`, `updatedAt`
- `settings`: グリッド、スナップ、精度、円近似、角度スナップ、面積表示単位
- `layers`: 名前、表示、ロック、色
- `entities`: 穴付きポリゴン、補助線・ポリライン・円弧・寸法・注記
- `groups`: 複数エンティティのグループ
- `constraints`: 頂点参照に対する寸法・幾何拘束

0.1 / 0.2 形式は段階的に現行形式へ移行します。プロジェクト全体のメタデータは厳格に
検証し、壊れた個別エンティティは理由を記録して破棄しながら残りを復元します。

## 構成

```text
src/
├── app/                 # Zustand ストア、プロジェクト型、履歴、レイヤー、スナップ
│   └── store/           # entity / primitive / geometry / layer / clipboard / history / UI actions
├── components/
│   ├── cad/             # ビューポート、プレビュー、HUD、右クリック、図形描画
│   └── layout/          # ヘッダー、ツールバー、パネル、プロジェクト・マニュアル UI
├── geometry/            # 純粋な幾何処理、検証、空間インデックス
├── persistence/         # localStorage、各種 import/export、共有 URL
├── i18n/                # 翻訳と日英マニュアル
├── styles/              # グローバル CSS とテーマ
└── tests/               # Vitest テスト
```

UI からクリッピングライブラリを直接呼ばず、`src/geometry/geometryEngine.ts` の
レジストリを使用します。既定は `clipper2-ts` で、比較・切り戻し用に従来の
`polygon-clipping` エンジンも保持しています。

## 既知の制限

- 円、楕円、円弧、フィレット、丸めオフセットは有限個の線分による近似です。
- SVG インポートは対応要素・パスコマンドのサブセットで、スタイル、テキスト、画像、
  `<use>` などを完全には再現しません。
- SVG / PNG / DXF 書出は表示中の図形・寸法・注記を対象とし、グリッド、HUD、
  一時測定、補助線、下絵は含みません。
- DXF は限定的な ASCII サブセットです。穴は独立した閉ポリラインとなり、
  DWG や CAD 固有の面・ハッチ情報は生成しません。
- ローカルプロジェクトとバックアップはブラウザの保存容量・保持期間に依存します。
- 下絵の追加・変形・表示切替・削除は Undo / Redo の対象外です。
- 共有 URL には長さ制限があり、リアルタイム共同編集機能はありません。
- 3D、BIM、DWG の読込 / 書出には対応していません。

## プライバシー

通常の作図、ローカル保存、変換処理はブラウザ内で完結し、このリポジトリに
アプリケーション用バックエンドはありません。共有 URL は図面データ自体を URL に含めます。
