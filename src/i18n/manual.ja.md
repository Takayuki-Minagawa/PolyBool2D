# PolyBool2D 操作マニュアル

PolyBool2D は、穴付きポリゴンの作図・編集、面積確認、ブーリアン演算、簡易 CAD データ交換を
ブラウザ内で行う 2D Web アプリです。

---

## 1. 画面構成

- **ヘッダー**: 新規作成、プロジェクト管理、JSON / SVG 読込、各形式への書出、共有 URL、
  Undo / Redo、言語・テーマ、ショートカット一覧、マニュアル
- **ツールバー**: 選択、作図、測定、頂点編集、ナイフ、ブーリアン、クリップボード操作
- **キャンバス**: 作図・選択・移動・頂点編集。マウスホイールでズーム
- **プロパティパネル**: 寸法・面積、変形、頂点・穴、レイヤー、アウトライナー、
  ジオメトリ操作、プロジェクト設定
- **ステータスバー**: 現在のツール、選択面積、操作ガイド、エラー

## 3. スナップ、直交、数値入力

### 座標スナップ

スナップを有効にすると、グリッド、表示中の頂点、辺、中点、ポリライン、円弧、補助線へ
カーソルが吸着します。補助線は表示される区間だけでなく、延長した無限直線がスナップ対象です。
グリッド、頂点、辺・中点、許容ピクセル数はプロジェクト設定で変更できます。

### 角度スナップと `Shift`

角度スナップを有効にすると、2 点目以降の方向は直前点を基準に既定 15° 刻みへ揃います（初期状態は無効）。有効 / 無効と刻み角は
プロジェクト設定で変更できます。作図中に `Shift` を押すと、水平・垂直の 90° 拘束が
優先されます。矩形作図では `Shift` が正方形拘束も兼ねます。

### 正確な長さを入力する

ポリゴン、穴、ポリライン、測定などの作図中にカーソルで方向を示し、正の数値をタイプして
`Enter` を押します。直前点から指定距離の位置へ次点が追加されます。`.` と `,` のどちらも
小数点として使用できます。円、補助線、ナイフも対応するプレビュー中に長さを適用できます。

入力中の値はキャンバス上の HUD に表示されます。`Backspace` で 1 文字削除、`Esc` で取消です。

### 寸法 HUD

作図中は次の値をリアルタイム表示します。

- ポリゴン、穴、ポリライン: 各辺長
- 矩形: W×H
- 円、円弧: 半径
- 楕円: X / Y 半径
- 補助線、ナイフ: 長さ
- 測定: 各区間長、累積長、直近 3 点の角度

## 4. 作図ツール

### ポリゴン

1. `P` を押し、頂点を順にクリックします。
2. `Enter`、または 3 点以上で始点付近をクリックすると確定します。
3. `Backspace` で直前点、`Esc` で作図全体を取り消せます。

自己交差するリングや面積を持たないリングは作成されません。

### 矩形、円、楕円

- **矩形 (`R`)**: 対角線をドラッグします。`Shift` で正方形になります。
- **円 (`C`)**: 中心から半径をドラッグします。
- **楕円 (`O`)**: 中心から X / Y 半径をドラッグします。

円と楕円は「円分割数」に従うポリゴンとして保存されます。

### 円弧、ポリライン、補助線

- **円弧 (`A`)**: 中心、始点、終点の順に 3 点をクリックします。短い側の円弧を折れ線近似で保存します。
- **ポリライン (`L`)**: 点を順にクリックし、2 点以上で `Enter` を押します。
- **補助線 (`D`)**: 2 点をドラッグします。表示・スナップでは無限直線として扱います。

これらは面積を持たない線要素です。アウトライナーから名前、表示、ロック、レイヤーを編集できます。

### 穴

1. 穴を追加するポリゴンを 1 つだけ選択します。
2. `U` を押し、ポリゴン内部に 3 点以上をクリックします。
3. `Enter` または始点付近のクリックで確定します。

外周の外へ出る穴、外周と交差する穴、自己交差する穴、既存穴と重なる穴は拒否されます。
穴の面積はポリゴンの実面積から差し引かれます。

### 測定

`M` を押して点を順にクリックします。区間長、累積長、3 点以上では直近の角度を表示します。
`Backspace` で直前点を削除し、`Enter` または `Esc` で終了します。測定線は保存されません。

## 5. 選択と編集

- クリックで単一選択、`Shift` + クリックで追加・解除します。
- 選択ポリゴン本体をドラッグすると、選択中のポリゴンをまとめて移動できます。
- 矢印キーはポリゴンと線要素の両方を移動します。
- 非表示またはロック中のエンティティは選択・編集できません。
- コピー / カット / ペーストはポリゴンと線要素に対応します。貼付のたびに少しずつ位置がずれます。
- 右クリックからコピー、カット、貼付、複製、Union、Difference、削除、レイヤー移動を実行できます。

### 頂点編集

ポリゴンを選択すると外周と穴の頂点ハンドルが表示されます。

- ハンドルをドラッグして移動
- `Alt` + ハンドルクリックで削除
- プロパティパネルで X / Y を直接入力
- `+` で次の辺の中点へ頂点を挿入
- `×` で頂点を削除
- 穴見出しのボタンで穴全体を削除

各リングは最低 3 頂点必要です。編集で自己交差などが生じたポリゴンは赤い輪郭になり、
ステータスバーに検証エラーが表示されます。

### 変形、整列、情報表示

プロパティパネルでは 90° または任意角度の回転、左右・上下反転、0.5× / 2× または
X / Y 任意倍率の拡縮ができます。複数ポリゴンでは端・中心揃え、3 つ以上では等間隔分布が
できます。選択ポリゴンの実面積、外周・穴面積、周長、外接 W×H、重心も表示します。

---

## 6. レイヤーとアウトライナー

### レイヤー

- `+` で追加し、`●` で新規作図先を選びます。
- 名前、色、表示、ロックを行ごとに変更できます。
- 選択をドロップダウンで指定したレイヤーへ割り当てられます。
- 最後の 1 レイヤーは削除できません。
- レイヤー削除時、所属エンティティは残っている別レイヤーへ移動します。

### エンティティアウトライナー

面、補助線、線、円弧を一覧します。行クリックで選択し、名前、表示、ロック、所属レイヤーを
直接変更できます。レイヤー側の非表示・ロックもエンティティへ適用されます。

---

## 7. ブーリアンと高度なジオメトリ

### ブーリアン

- **Union**: 2 つ以上の選択ポリゴンを結合します。
- **Difference**: 最初の選択を対象、残りをカッターとして差し引きます。
- **Intersection**: 共通部分だけを残します。
- **XOR**: 重ならない領域だけを残します。

### ナイフ

1. 対象ポリゴンを選択して `K` を押します。
2. 境界と 2 点以上で交差する直線をドラッグします。

直線の両側でクリッピングするため、穴付きポリゴンと複数交点に対応します。結果が複数片に
なる場合があり、分割前後の面積を検証してから確定します。境界と重なるストロークは拒否されます。

### 高度なジオメトリ

ポリゴンを選択し、プロパティパネルから実行します。

- **Offset**: 正の距離で外側、負の距離で内側へ丸めオフセットした新規図形を作成
- **Repair**: 自己交差・自己接触を正規化し、選択を修復結果で置換
- **Chamfer**: 全頂点を指定距離で直線的に面取り
- **Fillet**: 全頂点を指定半径の円弧近似へ置換
- **Minimum bounds**: 選択頂点群を囲む最小面積の回転矩形を追加
- **Convex hull**: 選択頂点群の凸包で置換
- **Simplify**: Douglas-Peucker 法で冗長な頂点を削減

内側オフセットや修復は、結果が複数図形になったり空になったりする場合があります。

## 8. プロジェクトとバックアップ

変更は約 400 ms 後にブラウザの `localStorage` へ自動保存されます。ヘッダーの
**プロジェクト** では、複数の保存済みプロジェクトを開く、名前変更、複製、削除できます。

保存内容が変わるたびに直前の正常な保存値を保持し、プロジェクトごとに最大 10 世代まで
残します。プロジェクト一覧の **バックアップ** を開き、日時とエンティティ数を確認して
**復元** を押してください。復元直前の状態も次のバックアップになります。

バックアップは同じブラウザ内だけにあります。ブラウザデータの消去や端末故障には備えられないため、
重要な作業は JSON にも書き出してください。

## 9. 読込、書出、共有

| 操作 | 内容 |
| --- | --- |
| **JSON読込 / JSON** | レイヤー、設定、面、線要素を含むプロジェクト全体を読込 / 書出 |
| **SVG読込** | `polygon`、`rect`、`circle`、`ellipse`、`path` をポリゴン化 |
| **SVG** | 表示中のポリゴンを穴付きパス、ポリライン・円弧を実線として書出 |
| **PNG** | SVG 書出結果を透明背景の PNG に変換。長辺最大 4096 px |
| **DXF** | ポリゴン外周・穴を閉、ポリライン・円弧を開 `LWPOLYLINE` で書出 |
| **面積CSV** | ポリゴンの面積・周長と、ポリライン・円弧の長さを出力 |
| **頂点CSV** | 外周、穴、ポリライン、円弧の各頂点座標を出力 |

SVG の直線パスは `M/L/H/V/Z` の絶対・相対コマンドに対応します。曲線はブラウザが
長さ計測 API を提供する場合にサンプリングされます。スタイル、テキスト、画像などは
完全には再現しません。

**共有URL** はプロジェクトを圧縮して URL ハッシュへ埋め込み、クリップボードへコピーします。
受信者が URL を開くと共有データがローカルプロジェクトより優先して読み込まれます。
8,000 文字を超えるハッシュは作成できません。URL を知る人は図面を復元できます。

## 10. プロジェクト設定

プロパティパネルで次を変更できます。

- 座標単位: mm / cm / m
- 面積表示単位: mm² / cm² / m²
- グリッド間隔
- 円・楕円・円弧の近似分割数
- グリッド / 頂点 / 辺・中点スナップと許容ピクセル数
- 角度スナップの有効 / 無効と刻み角（1°〜180°）
- 面積と座標の小数桁数

単位を変更しても既存座標の数値自体は換算されません。表示・解釈する単位が変わります。

---

## 11. 制限と注意

- 円、楕円、円弧、フィレット、丸めオフセットは線分近似です。
- SVG 読込は要素とパスコマンドのサブセットです。
- SVG / PNG / DXF 書出にはグリッド、HUD、測定表示、補助線を含みません。
- DXF の穴は独立した閉ポリラインです。DWG や面・ハッチ情報は生成しません。
- ローカル保存はブラウザ容量に依存し、リアルタイム共同編集には対応しません。
- 3D、BIM、DWG 読込 / 書出には対応していません。
